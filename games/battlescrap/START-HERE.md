# Resume Battlescrap
Use this checkout’s `codex/battlescrap-laptop-handoff` branch. The implemented content/save version is **holder-elements-v13**, schema **2**.

Read [README.md](README.md) for running and playing, then [ARCHITECTURE.md](ARCHITECTURE.md), [DECISIONS.md](DECISIONS.md) and [VERIFICATION.md](VERIFICATION.md) before changing rules.

The live [Design Draft](https://docs.google.com/document/d/1PlwHc5BWQdSv77xgSlSmNEiZIhgJ40cii22NKibvcFM) owns general rules, its **Rules Quick Sheet** tab is the player reference, the [spreadsheet](https://docs.google.com/spreadsheets/d/1hfWFhxm-Su-qtR_hVrzFt6GBW1ure8W4xmp1o8hF-Rg/edit) owns hero data, and the [Build Specification](https://docs.google.com/document/d/16-weAaDa4W7e4gC2jeiv_NN0cSAS_bcd_WATxPcDSAU) owns implementation requirements. Read Heroes, Regions and Rules & notes before coding and before delivery. Match stable IDs and headers; never restore stale hero values from old exports or code.

Keep approved visual masters under `assets/`; browser copies are under `public/`. Bisti has a deliberate initials placeholder. Earlier implementations and tests under `sources/` are historical material, not alternate current rules. Print PDFs are also historical and must not be presented as the current quick sheet.

The local game requires no other game or root install. No public deployment is implied by updating this branch.
