# Current print kit

starter-test-v11. Print current/Battlescrap-print-and-play.pdf at Actual size, single-sided, US Letter. See current/COMPONENTS.md. The existing output is included; rebuilding is optional.

On Windows with Python 3.11 or later: install requirements.txt, then run build_current.py followed by verify_current.py from this folder. Arial fonts must be installed in C:/Windows/Fonts. build.py supplies shared drawing helpers and reads the older digital content at ../src/content.ts; run build_current.py for current rules. Do not run build.py as the current-kit entry point.

The included PDF previews and verification.json are retained evidence. A successful structural check does not establish balance.
