# Galax prototype

Run `npm install`, then `npm run dev`. Choose 2–4 human/bot seats, generate typed actions, and use the state-first sector/action interface. Run `npm test`, `npm run build`, and `npm run smoke` for verification.

All tunable values are in `src/data/config.ts`. Card-schema rows live in `src/data/cards.json`. The JSON-friendly state and action log make seeded games reproducible.
